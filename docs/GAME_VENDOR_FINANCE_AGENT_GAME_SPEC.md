# 代理商 × 遊戲彙總報表規格

> 版本：0.1.0
> 更新日期：2026-08-07
> 狀態：前端原型已完成，待接正式 API 與後續資料契約確認

本文件描述 Provider Portal 的「代理商 × 遊戲彙總」報表。它承接財務總覽的篩選結果，將有效 Game Round 依代理商與遊戲彙總，提供營運與財務查看及追溯資料來源的入口。

完整的財務責任邊界、金額公式與 GGAP 對帳邊界，請一併參考 [`GAME_VENDOR_FINANCE_REPORTING_SPEC.md`](./GAME_VENDOR_FINANCE_REPORTING_SPEC.md)。

## 1. 頁面定位

本報表用來查看目前串接的各代理商，在指定時間與遊戲條件下的投注、派彩、輸贏與玩家統計。

本報表不是：

- 代理商管理或代理商設定頁面。
- 會員清單或會員管理頁面。
- GGAP 平台對帳結果頁面。
- 平台財務、平台結算或錢包頁面。
- 單筆 Game Round 明細頁。

## 2. 聚合單位與資料範圍

| 項目 | 定義 |
|---|---|
| 聚合單位 | 代理商 × 遊戲 |
| 主要資料來源 | Provider 保存的 Game Round |
| 環境 | 僅 `production` |
| 統計時間 | `settled_at` |
| 有效資料 | 已完成且有效結算的 Game Round |
| 代理商識別 | GGAP 傳入的代理商 ID / 顯示名稱 |
| 玩家人數 | 指定條件內實際產生有效 Game Round 的不重複玩家人數 |

「玩家人數」不是代理商的會員總數。Provider Portal 不管理 GGAP 會員主資料，因此只呈現指定條件下的活躍玩家彙總數，不顯示會員清單或會員個人資料。

## 3. 查詢條件

查詢條件包含：

- 時間區間。
- 代理商。
- 遊戲類型。
- 單款遊戲。

預設查詢範圍：

- 近 7 日，包含當日。
- 僅正式環境。
- 僅有效結算的 Game Round。
- 時區與財務總覽一致，原型顯示 `UTC+08:00 · Asia/Taipei`。

篩選行為：

- 未指定代理商時，列表每列呈現一組「代理商 × 遊戲」。
- 指定代理商時，可查看該代理商的各款遊戲。
- 指定遊戲時，可查看各代理商在該遊戲的數據。
- 同時指定代理商與遊戲時，只顯示該組合。

## 4. 篩選結果摘要

列表上方保留摘要區，預設顯示近 7 日的總和；套用時間、代理商、遊戲類型或遊戲篩選後，摘要區改為目前篩選結果的總和。

摘要項目：

- 投注總額。
- 派彩總額。
- 淨輸贏。
- GGR。
- 投注筆數。
- 玩家人數。

摘要統計必須計算完整篩選結果，不受目前列表分頁影響。金額以 Provider 點數為主，並提供 USDT 對照。

## 5. 主要列表欄位

欄位順序依照「識別 → 活躍規模 → 金額流向 → 結果 → 效率指標」：

| 順序 | 欄位 | 顯示方式 |
|---:|---|---|
| 1 | 代理商 | 名稱與代理商 ID |
| 2 | 遊戲 | 名稱與 Game ID |
| 3 | 遊戲類型 | 老虎機、單人 Crash、棋牌等 |
| 4 | 投注筆數 | 有效 Game Round 數量 |
| 5 | 玩家人數 | 指定範圍內不重複玩家人數 |
| 6 | 投注總額 | Provider 點數，附 USDT 對照 |
| 7 | 派彩總額 | Provider 點數，附 USDT 對照 |
| 8 | 淨輸贏 | Provider 點數，附 USDT 對照 |
| 9 | GGR | Provider 點數，附 USDT 對照 |
| 10 | 平均投注額 | Provider 點數，附 USDT 對照 |
| 11 | 人均投注額 | Provider 點數，附 USDT 對照 |

金額欄位主要顯示 Provider 點數，USDT 顯示於同一欄的輔助資訊或展開內容。欄位標題旁提供 info tooltip，說明公式、統計時間與換算規則。

## 6. 排序與分頁

- 主要列表欄位皆可排序。
- 預設排序建議為投注總額由高至低，正式實作前確認是否改為 GGR 或其他指標。
- 分頁是為了因應代理商與遊戲數量增加，原型可先呈現分頁骨架。
- 建議提供每頁 10、20、50 筆選項與總筆數。
- 排序應先作用於完整篩選結果，再進行分頁。
- 摘要區永遠依完整篩選結果計算，不只計算當前頁面。

## 7. Game Round 明細導入

點擊某一列後，沿用既有的正式 Game Round 紀錄頁 `/reports`，並帶入目前的：

- 時間區間。
- 代理商。
- 遊戲類型。
- 遊戲。
- 正式環境範圍。

明細頁每列代表一筆 Game Round，可查看：

- 結算時間。
- Provider Game Round ID。
- GGAP Round ID。
- 遊戲名稱與版本。
- 代理商。
- 會員 ID。
- 投注額、派彩額、淨輸贏。
- Provider 點數與 USDT 對照。
- 結算狀態。

不另建立重複的財務明細頁，避免 Game Round 明細與財務報表產生兩套不一致的資料呈現。

## 8. 自訂欄位匯出

使用者可開啟「匯出設定」視窗，自行選擇要匯出的欄位後產生 CSV 或 XLSX。

### 8.1 必要欄位

以下欄位預設固定保留，以確保匯出資料可追溯：

- 代理商 ID / 名稱。
- 遊戲 ID / 名稱 / 類型。
- 查詢時間區間。
- 報表產生時間。
- 時區。

### 8.2 可選欄位群組

- 活躍數據：投注筆數、玩家人數。
- 金額數據：投注、派彩、淨輸贏、GGR。
- 效率指標：平均投注額、人均投注額。
- 貨幣欄位：Provider 點數、USDT。

預設全部欄位勾選。匯出資料應以目前完整篩選結果為基礎，不受目前列表頁面限制。正式版本仍需確認權限、最大資料量、CSV / XLSX 限制與非同步產檔方式。

## 9. 空資料狀態

當篩選條件沒有符合資料時：

- 顯示清楚的「查無符合條件的彙總資料」訊息。
- 保留目前篩選條件，方便使用者調整。
- 提供清除篩選或重置操作。
- 摘要區顯示 `0` 或 `-`，不得顯示錯誤或 NaN。
- 無資料時停用匯出按鈕。

## 10. 原型階段限制

- 前端原型使用 mock data，不接正式 API。
- 正式版本的玩家去重必須由後端依查詢範圍正確計算，不能直接加總各遊戲玩家數。
- 匯出設定視窗與產檔流程可先完成畫面骨架，正式檔案服務後續接入。
- 分頁可先以少量 mock data 展示，正式資料量與查詢效能待後端契約確認。
- GGR 正式定義、正負方向、USDT 精度與換算規則版本仍待確認。

## 11. 不在本頁範圍

- 商戶欄位與商戶篩選。
- 會員 ID 列表與會員維度分析。
- 代理商管理、代理商設定與代理商開關控制。
- GGAP 對帳狀態、差異金額與對帳批次。
- 平台結算、錢包、佣金與分潤計算。
- DEMO 與測試環境資料。

## 12. 驗收方向

- 具備時間、代理商、遊戲類型與遊戲查詢條件。
- 預設顯示包含當日的近 7 日資料範圍。
- 摘要區會隨篩選結果更新。
- 列表欄位順序與規格一致。
- 玩家人數明確標示為不重複玩家人數。
- Provider 點數為主要金額，USDT 為對照資訊。
- 可從列表導入既有 Game Round 明細頁。
- 可開啟自訂匯出欄位設定。
- 具備分頁與空資料狀態骨架。
- 不出現商戶、會員管理、錢包或 GGAP 對帳語意。

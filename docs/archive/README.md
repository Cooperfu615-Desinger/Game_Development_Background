# 文件封存區

此目錄保存已完成、已過時或不再作為現行開發依據的文件。

封存文件的內容不代表目前 Provider Portal 的產品方向。需要了解目前需求時，請先閱讀 `docs/PROJECT_TRANSFER_INDEX.md` 與現行交接文件。

## 目錄

- `legacy/`：早期產品定位、架構分析、設計系統、開發計畫與技術轉移文件。
- `qa/`：舊版原型的 QA 報告。
- `superpowers/plans/`：已完成的歷史執行計畫。
- `superpowers/specs/`：已完成或已被新方向取代的歷史規格。

## 使用原則

- 只用於追溯決策、實作過程與測試紀錄。
- 不直接引用封存文件決定新功能範圍。
- 若需要重新啟用某項功能，應先建立符合目前 Provider Portal 方向的新規格。

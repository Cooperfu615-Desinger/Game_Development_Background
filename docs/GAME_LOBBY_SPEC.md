# Provider Portal 遊戲大廳工作規格

> 版本：0.1.0
> 更新日期：2026-08-06
> 狀態：工作規格，五個前端頁面與導覽骨架已建立；API、權限、正式資料契約與狀態碼待後續確認

本文件定義 Provider Portal「遊戲大廳」管理功能的頁面範圍、顯示規則與目前前端原型方向。遊戲大廳屬於 Provider 自有的玩家遊戲展示與 DEMO 試玩入口，與 GGAP 平台管理功能分開。

## 1. 頁面定位

遊戲大廳管理的主要目的為：

- 管理 Provider 自有遊戲在玩家遊戲大廳中的公開資料
- 管理遊戲大廳玩家看到的三種狀態與可試玩行為
- 管理遊戲簡述、遊戲參數、圖片與 YouTube 影片連結
- 查看 Demo 試玩結果，作為遊戲營運參考
- 透過完整大廳預覽，確認玩家實際看到的展示成果

遊戲大廳不負責 GGAP 平台錢包、代理商、商戶、會員、平台結算或代理商個別開關。GGAP 若要針對已由 Provider 上架的遊戲開啟或關閉，仍屬 GGAP 平台責任範圍。

## 2. 導覽與路由範圍

遊戲大廳位於「官方網站 > 遊戲大廳」底下，第一階段包含五個入口：

| 頁面 | 前端路由 | 頁面目的 |
|---|---|---|
| 大廳總覽 | `/lobby` | 查看遊戲數量、狀態與 Demo 摘要 |
| 遊戲清單 | `/lobby/games` | 查看大廳所有遊戲與基本公開資訊 |
| 遊戲管理 | `/lobby/management` | 編輯遊戲資料、參數、素材連結與玩家狀態 |
| DEMO環境數據 | `/lobby/demo` | 查看 Demo 玩家、Session、投注與遊玩時間 |
| 大廳預覽 | `/lobby/preview` | 預覽完整遊戲大廳展示成果 |

舊版 `/games/*` 路由仍保留作為相容與遷移參考，不代表新版遊戲大廳功能入口。

## 3. 大廳公開狀態

遊戲一定會顯示在大廳中，狀態只控制玩家是否可以啟動遊戲。第一階段固定使用以下三種狀態：

| 狀態 | 玩家看到的內容 | 玩家行為 |
|---|---|---|
| 即將開放 | 顯示遊戲名稱、簡述、圖片與基本資料 | 不可啟動，CTA 顯示「即將開放」 |
| 已推出 | 顯示完整公開資料 | 可以啟動 DEMO 遊戲，CTA 顯示「立即試玩」 |
| 維護中 | 保留已推出遊戲的公開資料 | 不可啟動，CTA 顯示「維護中」 |

狀態是玩家可見狀態，不另外在大廳新增 Provider 全域公開狀態。遊戲是否存在於大廳與是否可以試玩不拆成兩個玩家可見開關。

## 4. 大廳總覽

大廳總覽是進入遊戲大廳管理後的營運入口，目前原型提供以下摘要：

| 區塊 | 顯示內容 |
|---|---|
| 已推出遊戲 | 目前狀態為「已推出」的遊戲數量 |
| 即將開放 | 目前狀態為「即將開放」的遊戲數量 |
| 維護中 | 目前狀態為「維護中」的遊戲數量 |
| DEMO 活躍玩家 | Demo 當下或當日活躍玩家摘要；正式帳號數定義待確認 |
| 遊戲狀態 | 各遊戲目前的大廳狀態清單 |
| DEMO 今日摘要 | Demo 玩家、Session、投注與營運數字摘要 |
| 遊戲準備度 | 以 mock 資料呈現的資料完整度提示 |

總覽頁可快速連結至遊戲清單、遊戲管理、DEMO環境數據與大廳預覽。

## 5. 遊戲清單欄位與操作

目前桌機版遊戲清單使用寬表格，欄位順序如下：

| 欄位 | 顯示內容 |
|---|---|
| 遊戲 | 遊戲名稱、遊戲代碼與類型 |
| 版號 | Provider 遊戲目前展示版號 |
| 上架時間 | 遊戲上架時間；即將開放遊戲目前顯示 `—` |
| 狀態 | 即將開放、已推出、維護中 |
| RTP | 公開摘要 RTP，例如 `96.42%` |
| 波動度 | 低、中、中高、高等展示值 |
| 最高倍率 | 公開最高倍率，例如 `x2,000` |
| 操作 | 「詳情」導向遊戲管理；「預覽」導向大廳預覽 |

遊戲清單支援：

- 以遊戲名稱、遊戲代碼或類型搜尋
- 依全部、已推出、即將開放、維護中篩選
- 顯示所有已納入大廳的遊戲，包含尚未可玩的遊戲

遊戲清單不直接編輯完整遊戲參數、不管理 GGAP 代理商開關、不顯示 GGAP 對帳匹配狀態。

## 6. 遊戲管理

遊戲管理以單一遊戲為編輯單位，目前分為五個 Tab：

| Tab | 管理內容 |
|---|---|
| 基本資料 | Game ID、遊戲代碼、遊戲類型、版號、上架時間、最後更新時間、內部備註 |
| 遊戲參數 | RTP、波動度、最高倍率、幣別、最低投注、最高投注 |
| 公開內容 | 四語系遊戲名稱、簡述、玩法或公開說明 |
| 圖片與影片 | 遊戲卡片圖片、YouTube 影片 URL、可選的 YouTube 封面 URL |
| 狀態與公開檢查 | 三種玩家狀態、公開檢查清單與完整預覽入口 |

遊戲影片第一階段只保存 YouTube 連結，不建立本地影片上傳流程。圖片目前在原型中以展示素材表示，正式圖片儲存、尺寸與 CDN 規則待後續確認。

## 7. 公開檢查清單

公開檢查清單用於確認遊戲在大廳公開前的資料完整度，目前原型先提供以下檢查項目：

- 基本資料完整
- 四種語系內容已填寫
- 公開 RTP、波動度與最高倍率已確認
- 遊戲圖片已準備
- YouTube 影片連結格式已確認

檢查清單只作為 Provider 內部確認提示，不代表正式權限審核或外部法規驗證。完整檢查規則、阻擋發布條件與審批角色尚未定案。

## 8. DEMO環境數據

DEMO環境數據頁只呈現遊戲大廳 Demo 試玩結果，不列入正式遊戲財務報表。第一階段提供以下期間切換：

- 今日
- 近 7 日
- 近 30 日

主要摘要欄位：

| 指標 | 顯示內容 |
|---|---|
| 目前在線玩家 | Demo 當下活躍玩家數 |
| Game Session | Demo Session 累計數 |
| 投注筆數 | Demo 投注行為筆數 |
| 投注總額 | 以 USD 顯示的 Demo 投注總額 |
| 玩家活躍趨勢 | 以時間區間呈現的活躍玩家趨勢 |
| 遊戲表現 | 各遊戲玩家數、Session、投注筆數、投注總額與遊玩時間 |

### 8.1 DEMO 帳號規則

- 後端預期隨機生成 Demo 帳號，不建立固定帳號池。
- 每次產生帳號攜帶固定額度，原型以 `USD 10,000` 表示。
- DEMO環境數據是營運參考，不列入正式財務報表。
- 正式帳號生命周期、重置方式、資料保留期限與防濫用限制待後端契約確認。

## 9. 大廳預覽

大廳預覽直接呈現玩家遊戲大廳的完整展示成果，第一階段提供：

- 正式版本／編輯草稿預覽模式
- Desktop／Mobile 預覽切換
- 繁中、簡中、English、日本語切換
- 全部、老虎機、捕魚機、棋牌、小遊戲分類篩選
- 所有遊戲卡片與三種狀態 CTA
- 選取遊戲後查看遊戲詳情摘要
- Demo 餘額 `USD 10,000` 展示
- 簡單負責任遊戲宣告 Footer

「大廳預覽」是遊戲大廳專用預覽，不包含官方網站 Banner、條款、隱私權或公告活動內容，也不代表整體遊戲官網預覽。

## 10. 語系與金額顯示

- 玩家大廳目標支援繁中、簡中、英文、日文。
- 遊戲管理提供四語系公開內容編輯方向。
- 預覽頁提供四語系切換入口。
- Demo 與遊戲大廳展示金額以 USD 為主。
- 正式 Provider 點數與 USD 的換算規則不在遊戲大廳前端原型定義，仍依 Provider 自有規則與後續契約處理。

## 11. 資料模型方向

目前 mock 遊戲資料至少包含以下欄位：

| 欄位 | 說明 |
|---|---|
| `id` | Provider 遊戲識別 |
| `code` | 遊戲代碼 |
| `name` | 遊戲展示名稱 |
| `type` | 老虎機、捕魚機、棋牌、小遊戲等類型 |
| `version` | 目前展示版號 |
| `releaseAt` | 遊戲上架時間 |
| `status` | 即將開放、已推出、維護中 |
| `rtp` | 公開 RTP 摘要 |
| `volatility` | 波動度 |
| `maxMultiplier` | 公開最高倍率 |
| `minBet` / `maxBet` | USD 最低／最高投注 |
| `description` | 遊戲簡述 |
| `art` | 原型展示素材識別 |
| `youtubeUrl` | YouTube 影片連結 |
| `updatedAt` | 資料最後更新時間 |

以上是前端工作資料方向，不代表正式 API 欄位、資料型別、精度或狀態碼已定稿。

## 12. 視覺呈現

Provider Portal 管理介面使用淺色、低飽和的綠青色系，遊戲大廳預覽則使用深色玩家端展示區，區分「管理工作台」與「玩家成果」。

| 類型 | 顏色方向 |
|---|---|
| 已推出、可試玩 | 淡綠與青綠 |
| 即將開放 | 淡琥珀 |
| 維護中 | 淡珊瑚或橘灰 |
| Demo 與 USD | 深色底搭配青綠或金色數值 |
| 玩家大廳 | 深色夜景底、依遊戲使用不同色彩卡片 |

狀態 CTA 必須清楚表達是否可啟動，不使用僅依顏色判斷的設計。

## 13. 非本頁範圍

- GGAP 平台錢包、代理商、商戶與會員管理
- GGAP 平台結算與對帳匹配狀態
- GGAP 代理商個別遊戲開關
- Jackpot 主要導覽與 Jackpot 管理
- 遊戲官網 Banner、條款、政策、公告與活動
- 正式遊戲 Game Round 與財務報表
- 正式資料儲存、API、權限與審批流程
- 遊戲圖片正式上傳、CDN 與素材同步
- YouTube 連結正式驗證與影片嵌入策略

## 14. 待後續確認

- 三種大廳狀態的正式狀態碼與允許轉換規則
- 上架時間的時區、來源與是否允許手動調整
- 遊戲版號與遊戲大廳公開狀態的關係
- 四語系內容的 fallback 規則與缺少翻譯時的阻擋條件
- 圖片尺寸、檔案格式、儲存位置與 CDN 規則
- YouTube URL domain 驗證、封面圖與播放限制
- DEMO 帳號額度、Session 定義、資料保留與匯出格式
- Demo 數據的投注額、遊玩時間與玩家數計算口徑
- 公開檢查清單是否要成為發布前阻擋條件
- 正式 API、permission key、錯誤格式與審計紀錄

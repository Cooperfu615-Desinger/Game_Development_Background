# Provider Portal 遊戲列表工作規格

> 版本：0.1.0  
> 更新日期：2026-08-05  
> 狀態：工作規格，列表資訊架構已確認；部分資料契約與細節待後續確認

本文件定義 Provider Portal「遊戲列表」頁面的資訊架構、顯示規則與互動方向。環境與發布頁的完整操作流程另見導覽規格與後續專屬工作規格。

## 1. 頁面定位

遊戲列表是 Provider 遊戲營運的總覽入口，主要目的為：

- 快速查看 Provider 所有遊戲
- 同時比較正式、DEMO 與測試環境的目前版本與狀態
- 查看正式 / DEMO RTP 摘要
- 查看正式環境營運控制與 GGAP 目錄 / Release 同步狀態
- 透過版號、狀態與詳情入口前往對應頁面

遊戲列表不直接承擔完整版本設定、RTP 設定、限紅設定或素材上傳操作。

## 2. 列表範圍

- 顯示 Provider 的所有遊戲，包含尚未上線、尚未部署或尚未啟用的遊戲。
- 第一階段不建立或顯示額外的 Provider 全域狀態欄位。
- 遊戲是否尚未上線，透過正式 / DEMO / 測試環境狀態與篩選條件判斷。
- 不在遊戲列表管理代理商或商戶個別開關。
- 不在遊戲列表顯示素材上傳結果。

## 3. 欄位與順序

桌機版預設欄位順序如下：

| 欄位 | 顯示內容 |
|---|---|
| 遊戲代號 | Provider 遊戲識別 |
| 遊戲名稱 | 遊戲展示名稱 |
| 類型 | `slots`、`crash`、`table` 等遊戲類型 |
| 正式版號 | 正式環境目前生效的 Release |
| 正式狀態 | 正式環境狀態 |
| 正式 RTP | 正式環境實際 RTP 摘要，標題旁提供 Tips |
| DEMO 版號 | DEMO 環境目前生效的 Release |
| DEMO 狀態 | DEMO 環境狀態 |
| DEMO RTP | DEMO 環境實際 RTP 摘要，標題旁提供 Tips |
| 測試版號 | RD / 測試環境目前部署版本 |
| 測試狀態 | 測試環境部署狀態 |
| 營運控制 | 只代表正式環境的營運控制狀態 |
| GGAP 同步 | 遊戲目錄 / Release 同步狀態 |
| 操作 | 固定提供「詳情」入口 |

## 4. 表頭呈現

桌機版建議使用兩層群組表頭：

第一層：

```text
遊戲資訊 | 正式環境 | DEMO 環境 | 測試環境 | 營運控制 | GGAP 同步 | 操作
```

第二層：

```text
遊戲代號 | 遊戲名稱 | 類型
目前生效版號 | 狀態 | RTP
目前生效版號 | 狀態 | RTP
目前部署版號 | 狀態
狀態
同步狀態
詳情
```

列表以桌機寬表格為第一階段設計目標，暫不處理手機版配置。

## 5. 環境狀態

### 5.1 正式與 DEMO

正式與 DEMO 的狀態顯示：

- `上架`
- `維護中`
- `未啟用`

沒有目前生效版本時，版號顯示 `—`，狀態顯示 `未啟用`。不在列表區分「從未上架」與「曾上架後下架」；詳細差異留給環境與發布頁的版本歷程。

### 5.2 測試

測試環境等同 RD 開發環境，Provider Portal 只讀顯示：

- `未部署`
- `部署中`
- `已部署`
- `部署失敗`

測試環境不提供 Provider 的啟用、下架或版本切換操作。

## 6. 版本顯示與新版本提示

- 正式 / DEMO 版號代表該環境目前生效的 Release。
- 測試版號代表目前 RD 部署版本。
- Release 包含遊戲本體、RTP / 數學規則與限紅規則。
- RTP 或限紅若需要異動，應建立新的 Release，不直接修改已部署或已啟用版本。
- 正式與 DEMO 可以啟用相同或不同的 Release。
- 正式與 DEMO 各自判斷是否有新 Release。
- 若有較新 Release 已部署但尚未啟用，在對應正式或 DEMO 版號旁顯示 `＋` 提示。
- `＋` 不取代目前生效版號，只表示有新 Release 可查看或啟用。
- 沒有新 Release 時不顯示提示。

環境與發布頁尚未完成前，版號與狀態的導頁互動先保留，不提前實作。

## 7. RTP 顯示與 Tips

列表主欄位只顯示實際 RTP，例如：

```text
96.08%
```

正式 RTP 與 DEMO RTP 的標題右側各提供一個小型資訊圖示。Tips 顯示內容至少包含：

- 理論 RTP
- 實際 RTP
- 偏差
- 統計局數
- 統計時間區間
- 最後更新時間
- RTP 監控狀態

RTP 監控狀態只在 Tips 中顯示，不另外增加列表欄位。測試環境第一階段不顯示 RTP 欄位。

## 8. 營運控制

營運控制只代表正式環境，建議狀態為：

- `正常`
- `維護中`
- `暫停新局`

營運控制與正式環境的發布狀態分開表示。例如：

```text
正式狀態：上架
營運控制：維護中
```

點擊營運控制狀態，未來導向該遊戲的遊戲設定頁。維護期間可以啟用新 Release；啟用不會改寫既有 Game Round。

## 9. GGAP 同步

GGAP 同步欄位只表示正式環境的遊戲目錄 / Release 同步狀態，不代表代理商個別開關，也不代表平台對帳狀態。

建議狀態為：

- `已同步`
- `同步中`
- `同步失敗`
- `尚未同步`

點擊同步狀態，未來導向 GGAP 對接頁查看詳細同步與錯誤資訊。

## 10. 快速連結與操作

- 正式 / DEMO 版號：未來導向環境與發布頁，帶入 `gameId` 與 `environment`。
- 正式 / DEMO 狀態：未來導向對應環境的發布詳情。
- 新 Release `＋` 提示：未來導向對應環境的可啟用版本詳情。
- 營運控制：未來導向遊戲設定頁。
- GGAP 同步：未來導向 GGAP 對接頁。
- 操作欄：固定提供「詳情」。

詳情頁預留顯示：

- 正式、DEMO、測試三個環境摘要
- 各環境版本與狀態
- RTP 資訊
- 正式營運控制
- GGAP 同步狀態
- 設定完整度區塊或分頁

設定完整度檢查項目尚未定案，先保留擴充位置，不在本文件固定檢查清單。

素材上傳結果不列入遊戲詳情頁的本次範圍，素材由獨立資產管理頁處理。

## 11. 篩選、排序與分頁

### 篩選

- 遊戲代號 / 名稱
- 遊戲類型
- 正式狀態
- DEMO 狀態
- 測試狀態
- 營運控制
- GGAP 同步狀態
- RTP 監控狀態

### 排序

預設依遊戲 ID 排序。後續可支援：

- 遊戲名稱
- 最後更新時間
- RTP
- 正式環境狀態

### 分頁

- 每頁 10 筆

## 12. 視覺呈現

狀態使用低飽和、淡色背景搭配深色文字，不使用鮮豔高飽和色。

建議方向：

| 類型 | 顏色方向 |
|---|---|
| 上架、正常、已同步 | 淡綠 |
| 維護中 | 淡琥珀 |
| 暫停新局 | 淡橘灰 |
| 已部署、部署中、同步中 | 淡藍或藍灰 |
| 未啟用、未部署、尚未同步 | 淡灰 |
| 部署失敗、同步失敗 | 淡紅 |
| 新 Release 提示 `＋` | 淡琥珀或淡藍 |

RTP 主數值保持中性色，監控狀態只在 Tips 中使用淡色提示。

## 13. 非本頁範圍

- Provider 全域狀態
- 代理商或商戶個別開關
- Release 啟用與回滾
- 遊戲規則、RTP、限紅的完整編輯
- 素材上傳與素材同步
- 報表匯出
- 手機版列表
